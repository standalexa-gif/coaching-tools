Co aplikace dělá

Aplikace propojuje kouče a klienta do jedné sdílené session. Oba vidí stejná data v reálném čase a mohou společně pracovat v metodách.

Jak funguje klientský odkaz

Kouč vytvoří session a sdílí klientovi kód nebo odkaz. Klient se připojí přes vstupní stránku a otevře stejný prostor práce jako kouč.

Jak se ukládají data

Data session se ukládají do Firebase Realtime Database pod konkrétním kódem session. Ukládá se průběžný stav metod a metadata session (např. poslední aktivita).

Bezpečnost a přístup

Session je dostupná přes unikátní kód. Po ukončení session se klient už znovu nepřipojí. Přístupové chování je řízené databázovými pravidly.

Zabezpečení dat

Data jsou přenášena přes zabezpečené HTTPS spojení a ukládána ve Firebase Realtime Database. Přístup k session je omezen pomocí autentizace a bezpečnostních pravidel databáze podle role uživatele.

Kouč má přístup pouze ke svým session. Klient nepotřebuje účet a do konkrétní session se připojuje pouze prostřednictvím odkazu nebo kódu od kouče. Každá session je oddělena vlastním identifikátorem a po jejím ukončení je další klientský vstup zablokován.

Aplikace není určena pro ukládání citlivých osobních údajů, zdravotních informací, rodných čísel, přístupových údajů ani jiných dat, která nejsou nezbytná pro průběh koučovací session.
